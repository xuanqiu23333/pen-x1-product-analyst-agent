# PEN-X1 第二轮 Agent 升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有 PEN-X1 演示项目补齐真实数据 Provider、DeepSeek 结构化 Skill、Evidence/Claim 校验和规则化决策。

**Architecture:** Provider 负责采集与标准化，Runner 注入 Provider 和 LLM，Skill 只处理业务状态。Provider 或 LLM 失败时保持流程可运行，并将降级和警告写入 AnalysisState。

**Tech Stack:** Python 3.11、FastAPI、Pydantic v2、httpx、BeautifulSoup、Pandas、React、TypeScript、Vite。

**Spec:** `docs/superpowers/specs/2026-09-07-pen-x1-round2-design.md`

## Global Constraints

- 仅限 `feature/pen-x1-agent`，禁止 merge、force push 或修改 main/dev。
- 不创建 venv，不使用 Docker、代理池、验证码处理或 Amazon 评论爬虫。
- DEMO_MODE 必须离线完整运行；网络失败必须记录并降级为 Fixture。
- DeepSeek 结果必须经过 Pydantic；统计、利润、概率和 Gate 由 Python 处理。
